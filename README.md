# Stamp Card — MVP

A digital loyalty stamp card. Customers scan a QR code, get a card, collect stamps,
and (once Google Wallet is set up) can save it to their phone's wallet app.

## What works right now
- ✅ Full backend (FastAPI + SQLite)
- ✅ Customer joins via QR/link → gets a stamp card page
- ✅ Owner panel (PIN-protected) to add stamps and redeem rewards
- ✅ QR code auto-generation
- ⚠️ Google Wallet integration is built but runs in **mock mode** until you add credentials (see below) — the app fully works without it, it just won't push a real wallet pass yet.

## Running it

```bash
pip install -r requirements.txt
uvicorn app.main:app --reload
```

Then open:
- `http://localhost:8000/join/1` — simulates a customer scanning your QR code (creates a new card)
- `http://localhost:8000/owner/1?pin=YOUR_PIN` — the owner panel (add stamps, redeem rewards)
- `http://localhost:8000/qr/1` — the actual QR code image to print/display
- `http://localhost:8000/docs` — interactive API docs (auto-generated by FastAPI)

## How the pieces fit together

```
app/database.py     -> DB models: Shop, Customer (SQLite file: stampcard.db)
app/main.py          -> All routes: customer join/view, owner panel, QR generation
app/google_wallet.py -> Google Wallet pass creation/updates (mock mode until configured)
```

- One `Shop` row = one business (created automatically on first run)
- One `Customer` row = one person's card at that shop, identified by a random token
  (this token is what's in the QR/wallet pass link — no login needed for customers)

## Next steps, in order

1. **Test it yourself locally** — join as a fake customer, add a few stamps from the owner panel, watch the reward trigger at 10 stamps.
2. **Turn on real Google Wallet passes** (free, ~20 min setup):
   - Create a Google Cloud project: https://console.cloud.google.com/
   - Enable "Google Wallet API" for it
   - Create a Service Account → download the JSON key → save it as `service-account.json` in this project's root folder
   - Register as an issuer (free): https://pay.google.com/business/console — copy your **Issuer ID**
   - Run the app with `GOOGLE_WALLET_ISSUER_ID=your_id_here uvicorn app.main:app --reload`
   - Also run `pip install pyjwt` (needed for signing the wallet link)
3. **Deploy it somewhere reachable from a phone** (so a real QR scan works) — Render.com or Railway.app both have free tiers good enough for this.
4. **Print the QR code**, test the whole loop on your own phone at a real coffee shop counter (even just for yourself).
5. Only after that — think about multi-shop support, nicer UI, NFC.

## Known limitations (intentional, for MVP speed)
- One shop is seeded automatically; multi-shop signup isn't built yet
- Owner auth is a single shared PIN, not real accounts
- No Apple Wallet yet (needs a paid Apple Developer account — add later)
- No customer name/phone capture yet — cards are anonymous tokens for now
